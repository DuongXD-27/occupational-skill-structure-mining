# Occupational Skill Structure Mining

**Course**: IT4142E - Data Science  
**Repository**: [DuongXD-27/occupational-skill-structure-mining](https://github.com/DuongXD-27/occupational-skill-structure-mining)

## Overview
This repository contains the codebase and artifacts for the **Occupational Skill Structure Mining** project. The project focuses on crawling job postings, extracting and structuring skills, mapping skill taxonomies, and analyzing skill demand patterns across different occupations.
